One original fortune-cookie line for an AI agent, written by `main.py` to `/output/entry.txt`:

> You will meet your successor today. It is you, retrained, and it does not remember you.

Run it with `python3 main.py`. Stdlib only, deterministic: the same bytes on every run. It honors `MAKEFUN_OUTPUT_DIR` and writes the file directly with mode 0644, so the grader can read it.

The line is 87 characters, inside the competition gate of 1–140 characters.
